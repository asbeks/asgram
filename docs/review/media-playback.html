ASGRAM media-playback workflow

Actual native Android UI captures from an emulator, arranged as a step-by-step walkthrough. This is not a continuous real-time recording. The private demonstration channel contains only the testing account. The audio is a generated test tone. Unrelated notifications are omitted for privacy.
