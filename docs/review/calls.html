ASGRAM call and screen-sharing workflow

Actual native Android UI captures from an emulator, arranged as a step-by-step walkthrough. This is not a continuous real-time recording. The private demonstration channel contains only the testing account. Camera imagery comes from the emulator.

  1. Start a live stream from the private channel.
  2. Grant Android camera permission and start camera streaming.
  3. Use microphone, camera and leave controls in the active call.
  4. Choose Share screen and approve Android screen-capture consent.
  5. Screen sharing is active; Android provides a stop-sharing control.

Camera, microphone and media-projection services support user-started calls and sharing. Test media only; no private conversations or contact details are included.
