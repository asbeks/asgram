ASGRAM live-location workflow

Actual native Android UI captures from an emulator, arranged as a step-by-step walkthrough. This is not a continuous real-time recording. The private demonstration channel contains only the testing account. Coordinates are simulated (0.1, 0.1); no real device location or private conversations are included. Unrelated notification previews are omitted.

  1. Open a chat, choose Attach → Location, and grant Android location permission.
  2. The picker receives the simulated emulator position.
  3. Tap Share My Live Location and choose a duration before sharing.
  4. The private test channel displays the live-location message and countdown.
  5. Android displays an ongoing notification with Stop Sharing Location. Tapping this action stops sharing; the emulator's LocationSharingService was verified absent afterward.

User-initiated sharing only. ASGRAM's Android foreground service keeps the chosen sharing session visible and stoppable while the app is in the background.
