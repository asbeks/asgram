# ASGRAM
<!-- impeccable:product-schema 1 -->
## Platform
android
## Users
Anyone who wants a normal Telegram client. The first version must use familiar Telegram onboarding, chats, groups, channels, calls and settings without a media-only destination. An optional Abdii Sabaa channel invitation and shortcut complement messaging; the media hub remains deferred. The initial artifact is an Android app the owner can test on an emulator.
## Product Purpose
A separately installed unofficial Telegram client, owned and branded by Abdii Sabaa Media, with native Telegram communication flows and ASGRAM’s own visual identity. The initial media hub has been removed from active navigation at the user's request on October 29, 2026. The user confirmed this is a Telegram client and asked to create the Android app after reviewing the network study.
## Positioning
The normal Telegram account and messaging experience combined with the publicly confirmed Abdii Sabaa branches in one clearly organized native hub.
## Operating Context
Android phones, variable mobile data, Telegram accounts. Preserve Telegram's expected account/session, message, channel, call and notification behavior. Keep Fulbek, ASBEKS and other existing projects unchanged.
## Capabilities and Constraints
Base: official Telegram Android open-source client. ASGRAM has its own registered Telegram API identity, approved by the user and stored in an ignored local file. Real account sign-in still needs runtime verification; never ship Telegram sample credentials. No fictional chats, follower counts or authentication claims. Channel joins require explicit user action. Preserve official sponsored-message support. Retain GPL notices and publishable client source; signing keys and local credentials stay outside Git. A release cannot be called public or fully verified until actual login and required runtime checks pass.
## Brand Commitments
Name ASGRAM; associated with Abdii Sabaa Media. Use a distinct ASGRAM icon, not the official Telegram logo. Existing media identity uses green, red, black and white. Native Android screens, familiar messaging and a clear, uncluttered interface.

## Product Principles
- Preserve reliable Telegram communication.
- Keep messaging as home. Use the existing ASGRAM forest-green identity across native screens. An optional, dismissible channel invitation may introduce Abdii Sabaa; never join on an account holder’s behalf.
- Keep private Telegram data on the user's device/client pathway, not copied to an editorial server.
- Distinguish tested functionality, configuration dependencies and release status honestly.
